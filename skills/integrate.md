# INTEGRATE

Integration phase — connect workflow output to downstream systems or
follow-on workflows.

## Phase: 5

## Tools (examples)
- API clients (REST, GraphQL)
- Notification channels (Telegram, Slack, email)
- Database writers
- Workflow triggers (cron, webhooks)
- Issue trackers (GitHub, Linear, Jira)

## Workflow

1. Identify downstream consumers
2. Format the output for each
3. Push via the appropriate channel
4. Confirm delivery

## Output
Handoff to Document:
- Systems notified
- Data delivered
- Confirmation receipts
- Follow-up actions queued
