# ANALYZE

Analysis phase — reason about findings from scan, identify actionable
items, rank by impact.

## Phase: 3

## Tools (examples)
- Pattern matching
- Known-issue reference data
- Inference helpers
- Domain reference modules

## Workflow

1. Triage findings
2. Cross-reference with known-issue modules
3. Rank by impact
4. Document evidence

## Priority

1. Items with known-impact references
2. High-confidence patterns
3. Medium-confidence patterns
4. Low-confidence signals

## Output
Ranked findings with severity, evidence, and follow-up actions.
